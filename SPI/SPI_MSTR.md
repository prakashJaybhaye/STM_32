# STM32F446RE SPI1 Bare-Metal Bring-Up Guide

## Goal

Transmit a byte over SPI1 and verify it on a logic analyzer.

Expected result:

- SCK on PA5 (D13)
- MOSI on PA7 (D11)
- Data visible in SPI decoder

---

# 1. SPI Theory

SPI uses:

- SCK  : Clock generated by master
- MOSI : Master Out Slave In
- MISO : Master In Slave Out
- NSS/CS : Slave Select

For this experiment:

- STM32 = Master
- Logic Analyzer = Observer
- No slave device required

---

# 2. Pin Selection

SPI1 pins:

| STM32 Pin | Function | AF |
|------------|------------|----|
| PA5 | SPI1_SCK | AF5 |
| PA6 | SPI1_MISO | AF5 |
| PA7 | SPI1_MOSI | AF5 |

NUCLEO-F446RE:

| STM32 Pin | Header |
|------------|---------|
| PA5 | D13 |
| PA6 | D12 |
| PA7 | D11 |

---

# 3. Enable Peripheral Clocks

Before using peripherals, their clocks must be enabled.

GPIOA clock:

```c
RCC_AHB1ENR |= (1U << 0);
```

SPI1 clock:

```c
RCC_APB2ENR |= (1U << 12);
```

Without clocks, peripheral registers will not operate.

---

# 4. Configure GPIO Mode

Each GPIO pin has 2 MODER bits.

Alternate Function Mode = 10b

For PA5, PA6, PA7:

```c
GPIOA_MODER &= ~(0x3FU << 10);
GPIOA_MODER |=  (0x2AU << 10);
```

Result:

- PA5 = AF mode
- PA6 = AF mode
- PA7 = AF mode

---

# 5. Select Alternate Function

AF registers decide which peripheral is connected.

SPI1 requires AF5.

```c
GPIOA_AFRL &= ~(0xFFFU << 20);
GPIOA_AFRL |=  (0x555U << 20);
```

Result:

- PA5 -> SPI1_SCK
- PA6 -> SPI1_MISO
- PA7 -> SPI1_MOSI

---

# 6. Configure SPI1

## Master Mode

```c
SPI1_CR1 |= (1U << 2);
```

MSTR = 1

STM32 becomes SPI master.

---

## Baud Rate

```c
SPI1_CR1 |= (7U << 3);
```

BR = 111

SPI Clock = PCLK / 256

A slow clock is easier to inspect on a logic analyzer.

---

## Software Slave Management

```c
SPI1_CR1 |= (1U << 9);
```

SSM = 1

Software controls NSS internally.

---

## Internal NSS

```c
SPI1_CR1 |= (1U << 8);
```

SSI = 1

Prevents MODF (Mode Fault) in master mode.

---

## SPI Mode

Default values:

```text
CPOL = 0
CPHA = 0
```

This is SPI Mode 0.

---

## Enable SPI

```c
SPI1_CR1 |= (1U << 6);
```

SPE = 1

SPI hardware starts operating.

---

# 7. Sending Data

Function:

```c
void SPI1_SendByte(uint8_t data)
{
    while (!(SPI1_SR & (1U << 1)))
        ;

    SPI1_DR = data;

    while (SPI1_SR & (1U << 7))
        ;
}
```

---

## TXE Flag

```c
while (!(SPI1_SR & (1U << 1)));
```

TXE = Transmit Buffer Empty

Question:

"Can SPI accept another byte?"

TXE = 1 means yes.

---

## Write Data

```c
SPI1_DR = data;
```

Loads transmit buffer.

Example:

```c
SPI1_SendByte(0x32);
```

Binary:

```text
00110010
```

SPI hardware automatically shifts these bits onto MOSI.

---

## BSY Flag

```c
while (SPI1_SR & (1U << 7));
```

BSY = Busy

Wait until transfer completely finishes.

---

# 8. Main Loop

```c
while (1)
{
    SPI1_SendByte(0x32);

    SysTick_Timer_DelayMs(1000);
}
```

Every second:

- One SPI transfer occurs
- MOSI sends 0x32
- SCK generates 8 pulses

# 10. Decoder Settings

SPI Decoder:

- Clock = CH0
- MOSI = CH1
- Mode = 0
- MSB First

Expected decode:

```text
32
32
32
32
...
```
